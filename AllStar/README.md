# All Star Marine Services Website

Static HTML/CSS site ready for GitHub Pages.

## Included images
The `assets/` folder now includes local marine-themed image assets used for:
- Hero yacht
- Marine technician / About section
- Recent project cards
- Marina contact background

## Deploy to GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, then select `main` and `/ (root)`.
5. Save. GitHub will publish the site.

No server or database is required for this version.
